Моя перша Web-сторінка

Про себе

Мене цікавить світ сучасних технологій, тому я поступово вчуся створювати власні Web-сторінки та краще розуміти, як працює Інтернет. Для мене навчання є можливістю розвивати уважність, відповідальність і творче мислення. Я намагаюся виконувати завдання самостійно, аналізувати помилки та знаходити нові способи покращення результату.

У повсякденному житті я ціную організованість, спокійне спілкування та готовність працювати над собою. Мені подобається відкривати нові теми, читати корисні матеріали, експериментувати з оформленням сторінок і бачити, як звичайний текст перетворюється на зручний електронний документ. Особливо важливо для мене вміти застосовувати знання на практиці.

Моє хобі

Одним із моїх хобі є робота з комп'ютером і вивчення програмування. Це заняття допомагає розвивати логіку, терпіння та здатність розбивати складну задачу на прості кроки. Коли програма починає працювати правильно, з'являється приємне відчуття, що ідея стала реальною.

Також мені подобається оформлювати Web-сторінки: добирати кольори, шрифти, структурувати інформацію та робити текст зручним для читання. Таке хобі поєднує технічні навички й естетичний смак, тому воно є одночасно корисним і цікавим.

Програмування

package Task_Manager;

import java.time.LocalDateTime;

public class Note {
    private String title;
    private String content;
    private LocalDateTime createAt;
    private boolean completed;

    public Note(String title, String content, LocalDateTime createAt, boolean completed) {
        this.title = title;
        this.content = content;
        this.createAt = createAt;
        this.completed = completed;
    }

    public String getTitle() {
        return title;
    }

    public String getContent() {
        return content;
    }



    @Override
    public String toString() {
        return "title='" + title + '\'' +
                ", content='" + content + '\'' +
                ", createAt=" + createAt +
                ", completed=" + completed;
    }
}
